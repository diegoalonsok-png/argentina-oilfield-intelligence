# Argentina Oilfield Intelligence

Observatorio documental de importaciones argentinas de insumos químicos.

## Implementación
El archivo `index.html` contiene la interfaz. Para que funcionen los filtros, tablas y exportaciones debe existir `datos.json` en la raíz, con clave `registros` (array) y `fuentes` (array).

## Activar GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → `main` y `/(root)` → Save.

## Alcance de las cifras
Los registros importados no prueban consumo final por empresas petroleras ni proveedor comercial. Distinguir importador de comprador final y revisar derechos de redistribución de las fuentes.
